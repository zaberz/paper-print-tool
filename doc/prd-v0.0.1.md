## 1. 背景与目标

### 1.1 背景
简印是一家传统印刷工厂，为拓展获客渠道，计划搭建官方网站，将"AI 在线设计 → 一键询价 → 工厂生产"链路打通。用户无需专业设计能力即可在站内生成可用于印刷的效果图，并提交询价，由销售人工跟进成交。

### 1.2 目标
- 上线一个对外门户，展示工厂业务能力与联系方式。
- 提供基于模板的 AI 设计编辑器，降低用户设计门槛。
- 通过询价表单沉淀意向线索，反哺线下销售。
- 沉淀技术底座（前端框架 + Supabase 后端 + 可插拔 AI 服务），为后续闭环交易预留扩展空间。

### 1.3 非目标（v0.0.1 不做）
- 在线支付与订单生产管理流程。
- 画册/手册等多页装订品的深度编辑（仅首页展示承接能力，不开放编辑）。
- CMYK 印刷规范文件、出血线导出（输出 PNG 即可，专业印刷文件由工厂后处理）。
- 复杂会员体系、积分、营销活动。

## 2. 目标用户

| 用户类型 | 典型场景 | 诉求 |
| --- | --- | --- |
| 中小企业/个体户 | 门店开业、促销传单、折页 | 傻瓜式出图、快速询价 |
| 广告/设计公司 | 客户提案初稿、快速打样 | 高自由度微调、可下载高清素材 |

## 5. 详细功能需求

### 5.1 首页

**目标**：5 秒内让用户明白"我们是印刷工厂 + 提供 AI 在线设计"。

**页面结构（从上到下）**：

1. **顶部导航**
   - Logo「简印」
   - 导航项：首页 / 在线设计 / 印刷品类 / 关于我们 / 联系我们
   - 右上角：登录/用户头像 + 「开始设计」主按钮

2. **Hero 区**
   - 主标题：如「AI 一键设计，工厂直印」
   - 副标题：简述能力（在线设计 → 询价 → 工厂生产）
   - CTA：「立即开始设计」「查看印刷品类」
   - 背景视觉：印刷主题配图（靛蓝→暖橙渐变 + 工厂实景/印刷品合成图）

3. **业务介绍区**
   - 三栏卡片：
     - 「AI 在线设计」- 选模板填文字即可生成效果图
     - 「专业印刷生产」- 海报/折页/名片等多品类
     - 「询价即响应」- 提交需求，销售 1 工作日内跟进

4. **印刷品类区**
   - 海报/传单、宣传折页、名片三类卡片展示（画册标注"承接定制"）
   - 每张卡片点击 → 跳转编辑页并预选该品类

5. **流程区**
   - 4 步图示：选模板 → 填内容 → AI 生成 → 询价下单

6. **关于我们**
   - 工厂简介（占位文案，待补充）
   - 工厂实景图位（占位）

7. **联系方式/页脚**
   - 手机号、QQ、淘宝店链接
   - ICP 备案号（待补充）

### 5.2 编辑页（核心）

#### 5.2.1 页面布局

```
┌─────────────────────────────────────────────────┐
│  顶部栏：品类切换 | 模板库 | 重新生成 | 导出PNG | 询价 │
├──────────┬──────────────────────┬───────────────┤
│ 左侧     │  中间画布 (fabric.js) │  右侧属性面板 │
│ 步骤导航 │  分层：背景层+文字层   │  选中元素属性 │
│ - 品类   │  实时预览             │  - 文字内容   │
│ - 模板   │                       │  - 字号       │
│ - 内容   │                       │  - 颜色       │
│ - 生成   │                       │  - 位置       │
│ - 微调   │                       │  - 对齐       │
└──────────┴──────────────────────┴───────────────┘
```

#### 5.2.2 步骤说明

**Step 1：选择品类**
- 选项：海报/传单、宣传折页（二折/三折/四折）、名片（正反面）
- 选择后画布尺寸自适应（见 6.3 尺寸规范）

**Step 2：选择模板（预制骨架）**
- 工厂预制模板库，按品类 + 行业/风格分类（如餐饮、教育、活动、商务）
- 模板包含：背景图占位、文字图层占位（标题/副标题/正文/联系信息）、布局信息
- v0.0.1 首批提供不少于 12 套模板（每品类 4 套起）
- 模板存储于 Supabase（元数据）+ 对象存储（背景图素材）

**Step 3：填写内容**
- 表单字段根据模板动态生成，常见字段：
  - 主标题、副标题
  - 正文/卖点描述
  - 联系方式（电话/地址/二维码文案）
  - 风格描述（可选，用于引导 AI 生成，如"清新/活力/商务"）
- 支持一键应用占位示例文案

**Step 4：AI 生成**
- 用户点击「AI 生成效果图」，系统调用 AI 服务层：
  - **生成效果图**：整图合成，用于预览展示（不可编辑）
  - **生成素材图**：背景图（AI 生成或模板自带）+ 文字图层（基于用户填写内容自动排版）
- 生成完成后，素材图加载到 fabric.js 画布：
  - 背景图层：锁定不可移动（可重新生成）
  - 文字图层：可选中、微调字号/位置/颜色/对齐
- 生成耗时较长，需 loading 动画 + 进度提示

**Step 5：微调与导出**
- 选中文字图层 → 右侧属性面板调整
- 顶部「重新生成」：仅重生成背景图，保留文字内容
- 顶部「导出 PNG」：按印刷分辨率导出（见 6.3）
- 导出后弹窗：「立即询价」/「继续编辑」

#### 5.2.3 折页特殊处理
- 二折/三折/四折页画布按折面分块显示（如三折页显示 3 个并排画布区域）
- 每个折面独立编辑文字图层，背景图整体生成
- 导出时按折面拼接为完整展开图

#### 5.2.4 名片特殊处理
- 正反两面切换 Tab
- 每面独立画布与文字图层

### 5.3 询价表单

**触发入口**：
- 编辑页导出后弹窗的「立即询价」
- 顶部栏「询价」按钮（可直接进入，不强制先设计）

**表单字段**（简化版）：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| 品类 | 单选 | 是 | 海报/折页/名片/其他 |
| 数量 | 数字 | 是 | 最小起印量提示 |
| 联系方式 | 文本 | 是 | 手机号或微信 |
| 备注 | 多行文本 | 否 | 尺寸/纸张/交付等特殊要求 |
| 关联作品 | 自动 | 否 | 若从编辑页进入，自动带上作品 ID |

**提交后**：
- 提示「询价已提交，销售将在 1 工作日内联系您」
- 数据写入 Supabase `inquiries` 表
- 销售后台（v0.0.1 用 Supabase Studio 直接看表，不做独立后台）

### 5.4 账号体系（可选登录）

- **未登录**：可使用全部功能（设计/生成/导出/询价），作品不保存
- **登录方式**：手机号 + 短信验证码（Supabase Auth）
- **登录后能力**：
  - 作品历史列表（保存最近 N 次生成的作品，含效果图与可编辑素材图快照）
  - 询价历史
- **登录入口**：顶部栏「登录」按钮，登录后显示头像
- **不做**：第三方登录、密码登录、个人资料编辑（v0.0.1）

### 5.5 AI 服务层（可插拔）

**设计目标**：AI 文生图服务可替换，首版预留接口 + Mock 实现，便于后续接入国内服务商（通义万相/可灵/即梦）或自部署 SD。

**接口抽象**（伪代码）：

```ts
interface AIGenerateService {
  // 生成整图效果图
  generatePreview(params: {
    category: string;       // 品类
    templateId: string;     // 模板 ID
    content: ContentInput;  // 用户填写的文字内容
    styleHint?: string;     // 风格描述
  }): Promise<{ imageUrl: string }>;

  // 生成素材图（背景图 + 文字图层布局数据）
  generateAssets(params: {
    category: string;
    templateId: string;
    content: ContentInput;
    styleHint?: string;
  }): Promise<{
    backgroundImageUrl: string;        // 背景图
    textLayers: TextLayerLayout[];     // 文字图层排版数据（内容/位置/字号/颜色）
  }>;
}
```

**首版实现**：
- `MockAIGenerateService`：返回模板自带的占位背景图 + 按模板预设布局生成文字图层
- 后续替换为真实服务商实现，业务代码无感知

## 6. 技术方案

### 6.1 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 前端框架 | TanStack Start | 文件路由 + SSR |
| UI 组件库 | shadcn/ui | 基于 Radix + Tailwind |
| 画布编辑 | fabric.js | 分层编辑、文字微调、PNG 导出 |
| 后端/BaaS | Supabase | Auth + Postgres + Storage |
| AI 服务 | 可插拔（首版 Mock） | 预留接口 |
| 部署 | 已有域名+服务器 | ICP 备案号待补充 |

### 6.2 主色调

| Token | 色值 | 用途 |
| --- | --- | --- |
| primary | Indigo `#4F46E5` | 主按钮、导航、品牌色 |
| accent | Orange `#F97316` | CTA 强调、装饰、AI 生成按钮 |
| neutral | Slate 系 | 文字、背景、边框 |

### 6.3 印刷尺寸与导出规范

| 品类 | 画布尺寸（mm） | 导出分辨率 | 导出格式 |
| --- | --- | --- | --- |
| 海报/传单 | A3(297×420) / A4(210×297) | 300 DPI | PNG |
| 二折页 | 展开A4(210×297) | 300 DPI | PNG |
| 三折页 | 展开A4(210×297) | 300 DPI | PNG |
| 四折页 | 展开A3(297×420) | 300 DPI | PNG |
| 名片 | 90×54（单面） | 300 DPI | PNG |

> fabric.js 画布按物理尺寸 + 300 DPI 计算像素尺寸，编辑时缩放显示，导出时按原始分辨率输出。

### 6.4 数据模型（Supabase Postgres，核心表）

```sql
-- 模板表
templates (
  id uuid pk,
  category text,          -- poster/flyer/fold/business_card
  sub_type text,          -- 二折/三折/四折（折页用）
  name text,
  industry text,          -- 行业分类
  style text,             -- 风格分类
  background_placeholder text,  -- 占位背景图 URL
  text_layer_schema jsonb,      -- 文字图层占位定义
  layout jsonb,                 -- 排版布局
  sort int,
  is_active bool,
  created_at timestamptz
)

-- 作品表
artworks (
  id uuid pk,
  user_id uuid,                 -- 可空（未登录）
  template_id uuid,
  category text,
  content jsonb,                -- 用户填写的文字内容
  preview_image_url text,       -- AI 生成的效果图
  background_image_url text,    -- 素材背景图
  text_layers jsonb,            -- 文字图层最终状态
  created_at timestamptz
)

-- 询价表
inquiries (
  id uuid pk,
  user_id uuid,                 -- 可空
  artwork_id uuid,              -- 可空
  category text,
  quantity int,
  contact text,
  remark text,
  status text default 'new',    -- new/contacted/closed
  created_at timestamptz
)
```
